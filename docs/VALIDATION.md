# Проверка версии 1.0.0

Проверено 19 ноября 2026 года на Windows.

- Сборка EXE компилятором .NET Framework: успешно, без предупреждений.
- Сборка установщика Inno Setup 6.7.1: успешно.
- 17 автоматических проверок: безопасный старт, столкновение, остановка завершённой игры, столкновение с быстрой машиной, победа, границы движения, скорость движения, диагональное движение, ограничение числа машин за минуту симуляции, оба направления движения, изменение потока при другом seed, сложность, первоначальная запись и замена настроек, чтение настроек, восстановление после повреждения и отсутствия файла.
- Проверка обработчиков интерфейса: меню мышью и клавиатурой, сложность, движение, пауза, возврат из настроек в паузу, потеря фокуса, экран столкновения, повтор, экран победы и счётчик переходов.
- Шесть экранов отрисованы; просмотрены изображения меню, игры, настроек, паузы, поражения и победы.
- Тихая установка в отдельную тестовую папку: код 0. Хеш установленного EXE совпал с исходным. Автотесты установленного EXE: код 0. Удаление тестовой копии: код 0.

UI-проверки вызывают настоящие обработчики событий и отрисовку программно. Ручное прохождение с физической клавиатурой, живое наведение мышью и прослушивание звуков не проверялись. Установщик проверен вне песочницы: внутри неё Windows не предоставила путь к локальной папке данных пользователя.
